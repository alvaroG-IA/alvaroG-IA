## 🔬 Featured Research & Projects

### 𓏞 Multimodal VLM Alignment & Domain Adaptation
*Solving extreme domain shift and data scarcity in historical scripts via multimodal representation learning.*
- **Key Contributions:** Designed a comparative research framework evaluating classical supervised Computer Vision baselines against a novel Vision-Language approach to mitigate domain shift and data scarcity.
- **Core Methodology:** Proposed a multimodal alignment pipeline using foundation models (CLIP) and contrastive learning (InfoNCE) to align text-image embedding spaces, achieving robust domain invariance over real historical artifacts.
- **Tech:** PyTorch, CLIP, Hugging Face, FAISS, Ollama, UMAP, OpenCV, CUDA.

### 🤖 Multimodal AI Agent System for Product Intelligence
*End-to-end agentic architecture combining perception, retrieval, and generative pipelines.*
- **Key Contributions:** Built an LLM-orchestrated multimodal agent enabling natural-language control of complex perception workflows. Integrated CLIP embeddings, SAM (Segment Anything), Diffusion Models, and RAG pipelines for structured image-text insight extraction.
- **Tech:** LangGraph, Ollama, CLIP, SAM, Diffusers, Transformers, Python.
